## Introduction

This repository aims to create a deep learning model to detect keypoints during a golf swing. It aims to improve the learning process and provide quicker insight on to what went wrong 
on missed shot, and to be able to compare your own swing to professionals'.

## Future work

For now, the keypoint detection is working on the MPII Human pose dataset. The next step is to create a new dataset with added keypoints such as golf club head, golf ball, to have greater insight
during the golf swing.

After that is obtained, it would be possible to try and lift the 2D keypoints in 3D using one other model. This model choice is still to be made.

Once the 3D keypoints obtained, it is possible to gather information from the golf swing, and convert it into real work insight for the player.
